PROYECTO DESTACADO

FotoTrack

Plataforma para Resolana Fotografía que permite explorar álbumes de eventos MTB, encontrar fotos mediante reconocimiento facial y comprar imágenes.

  • Procesamiento de imágenes, miniaturas y marca de agua configurable.
  • Autenticación, roles de usuario y panel de administración.
  • Carrito, compras y entrega de originales mediante enlaces temporales.

Mi trabajo: análisis de requerimientos, modelado relacional, interfaz en React y API REST con arquitectura por capas.
